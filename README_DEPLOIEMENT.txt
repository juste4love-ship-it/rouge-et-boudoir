ROUGE & BOUDOIR — V5 PRODUCTION

Architecture
- rougeetboudoir.com : site vitrine premium (Netlify)
- www.rougeetboudoir.com : redirection vers le domaine principal
- boutique.rougeetboudoir.com : Shopify
- bonjour@rougeetboudoir.com : messagerie professionnelle

Le code est statique, rapide et ne contient aucun secret/API.
Le checkout, le catalogue, les paiements, les stocks et les commandes restent dans Shopify.

Avant mise en production :
1. connecter le dépôt GitHub au projet Netlify ;
2. connecter rougeetboudoir.com et www ;
3. créer le sous-domaine boutique et le connecter à Shopify ;
4. valider les DNS chez Namecheap ;
5. contrôler le SSL ;
6. tester desktop/mobile et tous les liens ;
7. finaliser mentions légales/CGV dans Shopify avant vente.
